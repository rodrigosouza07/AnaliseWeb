# Análise de Uso de Redes Sociais por Estudantes

Este projeto tem como objetivo analisar padrões de uso de redes sociais entre estudantes, com foco em:
- plataforma principal de uso;
- horas de uso diário e no fim de semana;ç
- tipo de dispositivo mais utilizado;
- distribuição por gênero;
- relação com idade e sono.

A análise foi desenvolvida em um notebook Jupyter e utiliza um conjunto de dados de estudantes com métricas sobre comportamento digital e hábitos de sono.

## Visão geral

O dataset contém informações sobre 4.500 estudantes, incluindo:
- ID do estudante
- Idade
- Gênero
- Nível acadêmico
- Plataforma principal
- Horas de uso diário
- Horas de uso no fim de semana
- Tipo de dispositivo
- Duração do sono
- Qualidade do sono

## Objetivo

Identificar:
- quais plataformas são mais usadas;
- como os estudantes distribuem seu tempo nas redes sociais;
- quais dispositivos predominam em cada plataforma;
- se existem diferenças de uso por gênero;
- como a média de idade e tempo de uso variam entre as plataformas.
